# Modern Dynamics Forge (MD)
A port of https://github.com/Technici4n/Modern-Dynamics to forge 1.20.1. Based on the fabric 1.20.1 branch with reference to neoforge 1.21.1.

The pipe model rendering system was also rewritten for performance on heavier modpacks, where it was abundantly obvious that there was issues.
